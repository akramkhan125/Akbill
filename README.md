# Akbill

Unit billing calculator in Pakistani Rupees. Made by Akram Khan.

- Per-customer flow: name → multiple unit terms → "Add All" sums terms → × rate = bill
- Amounts rounded to the nearest PKR 10 (half-up)
- Running grand totals, full-bill and per-customer print, amount-in-words (lakh/crore)
- PDF download (pure-JS, works offline), WhatsApp share
- 10 accent themes, EN/اردو UI toggle, light/dark mode, sound effects
- Installable offline PWA

Built with React 19, Vite, TanStack Router/Start and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
